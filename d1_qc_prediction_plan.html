PART 01 · 为什么是现在

"测完才知道"是 CDMO 业务最大的反应式痛点

凯莱英年商业化生产 800 批左右 × 单批 200 万价值。1% 报废率 = 1600 万损失/年。 报废的 80% 是 QC 检测后才发现的 —— 如果能在批中期或结束前 AI 预测出风险，提前干预，可以挽救 50%+。

业务痛点

🔴 报废发现太晚
  • QC 检测在批结束后 3-7 天才出结果
  • 发现不合格 → 只能降级 / 返工 / 报废
  • "做完一批才知道这批不行"的损失最大
🔴 QC 等待拖累客户交付
  • 放行慢 → 客户拿货慢 → 影响下单 / 复购
  • 放行慢 → 仓储成本上升 → 资金占用
  • 不能"先发货后放行"（GMP 强约束）
🔴 QC 工程师"机械汇编"工时高
  • 检测结果填表 / 拼报告 / 趋势对比占 50% 工时
  • 资深 QC 应该做"异常解读"而非"数据搬运"
  • 跟方向 ② 报告 AI 撰写同源问题
💡 升级思路
  • 批生产中期 / 结束前，AI 用历史批 + 本批工艺数据预测 QC 结果范围
  • 给"高概率合格 / 重点关注 X 项 / 高风险"三级判断
  • 同时自动生成 QC 报告草稿（结构化 + 数据图表 + 合规声明）
  • 高风险批 → 工艺工程师介入早期干预；低风险批 → 走加速放行

PART 04 · 技术路线

多源数据汇集 → 预测模型 → 置信度评估 → QC 报告草稿

技术上有3 个核心挑战：① 单项目数据稀疏（30 批"小数据"）；② 跨项目隔离限制学习；③ 偏差批样本少。 解决方案是贝叶斯先验 + 迁移学习 + 主动学习。

💡 三个核心技术挑战的应对
  • 挑战 1 · 数据稀疏：单项目 30 批属"小数据" → 用贝叶斯先验启动 + 主动学习（每批反馈调模型）
  • 挑战 2 · 客户隔离：不能跨客户混训 → 只学"工艺规律"不学"具体参数" → 联邦学习 + 差分隐私
  • 挑战 3 · 偏差样本少：负样本（不合格批）罕见 → 合成数据扩充 + 异常检测算法（不依赖大量负样本）

PART 10 · 决策建议

重点决策 5 件事

①
立项 — 长期战略，M6 启动 PoC

本方向是 6 方向里ROI 最大但落地最难的（长期战略）。建议 M1-M5 跟方向 ② 共建底座，M6 启动 PoC，不要急着上。

②
PoC 项目选定 — 1 个商业化稳定项目

选标准：① ≥30 批历史；② 数据完整（IPC + QC + 原料 COA + PAT）；③ 工艺研发愿意配合 ≥4 个月。建议工艺研发 + QC + QA 联合提名 3 个候选，副总裁拍板。

③
技术路线 — 多供应商混合 + 自建底座

① 智现未来做 FDC 算法 PoC 对照；② LLM + RAG 跟方向 ② 共用；③ GAMP 5 验证自建。不让单一供应商绑定。

④
监管路径 — 早期 QA + 法规事务介入

放行决策是 GMP 强监管项。QA + 法规事务必须从 PoC 起就介入，提前对齐"AI 草稿 + 人工签字"+ GAMP 5 验证方案 + 客户合同附件。

⑤
底线 — AI 永远不替代 QC 检测和人工签字

这是不可妥协的底线。AI 只做 ①预测 ②报告草稿 ③放行建议，所有批仍 100% 全检，所有放行仍 QC + QA 双签字。 对外宣称定位为"QC 工程师辅助工具"，不宣称"AI 放行"。
