# 生产管理 AI 表格使用说明

v1 ｜ 2026-11-10 ｜ Base：生产管理（试点）

> 一句话：计划员排批次，车间更新执行情况、登记进展和延误；日报、周计划、月计划、预警和统计都由系统自动生成。

## 一、整体流程

```
① 一次性准备      车间（生产文员）            延误原因（已导入，26 类）
② 订单            订单同步（自动同步，不手填）
③ 立项            项目（项目组）  ── 关联订单
④ 工艺准备        工艺步骤（项目组 + 生产部）  标准系数、标准周期、排产参数
⑤ 排产            批次（计划员）  参考"建议计划"填写 V1 和最新计划
⑥ 执行            批次（车间）    每天更新状态、实际开始/结束、产量
                  现场记录（车间）有进展或延误时登记一条
⑦ 查看与预警      报表视图（📋）、统计视图（📈）、仪表盘；每天 08:30 推送预警
```

**按角色的日常工作**

| 角色 | 每天 | 每周 | 每月 / 不定期 |
|---|---|---|---|
| 生产文员 | — | — | 新增或调整车间；维护生产经理 |
| 项目组 | 关注项目统计和预警 | 查看 📋 下周计划 | 立项时建项目、工艺步骤 |
| 生产计划员 | 处理预警，调整最新计划 | 周五检查下周计划 | 新项目排产，填 V1 计划 |
| 车间 | 在 ✏️ 车间更新里改状态；在 ✏️ 现场填报里登记进展和延误 | — | 月底补三废数量 |
| 管理人员 | 看 📋 预警清单、仪表盘"生产总览" | 看 📈 车间统计、📋 本周未完成 | 看 📋 本月计划、仪表盘"延误分析" |

## 二、表说明

字段分两类：**【填写】**是人填的，字段描述里写明了由谁填；**【自动】**是系统计算的，不需要填，也改不了。每张表都有"✏️"开头的填写视图，里面只显示要填的字段，日常填写尽量在这些视图里操作。

### 2.1 车间

- **是什么**：每个车间一行，是基础数据，同时承载车间统计。
- **谁填**：生产文员，一次性填好。
- **要填**：车间编码（格式"厂区-车间"，如 DH1-二车间）、厂区、车间名称、生产经理。生产经理会收到本车间批次的预警消息。
- **自动生成**：批次总数、在制批次数、红色预警数、本周和本月的投入、结束、计件统计及完成率、延误合计。

### 2.2 延误原因

- **是什么**：26 类延误原因，并归入 8 个大类，已导入。
- **用法**：登记延误时从这里选择原因。不建议随意增删，否则历史统计会对不上；确实需要调整时，由生产部统一修改。

### 2.3 订单同步

- **是什么**：订单部门 AI 表格的同步副本，每张订单一行。
- **用法**：只读，不要手工修改，字段描述都标了【同步】。项目表通过"关联订单"引用这里的交期。
- **现状**：同步方式还在和订单部门确认。确认之前，如需测试，可以临时手工录入几条。

### 2.4 项目

- **是什么**：每个项目（一次生产）一行，连接订单和生产，同时承载项目统计。
- **谁填**：项目组，立项时填写。
- **要填**：项目号（如 CPo127075-04）、项目类型、项目类别、GMP级别、项目主管、Coreteam、Coreteam负责人、生产配对负责人、主生产厂区、项目状态、关联订单。
- **自动生成**：客户要求交期、内部承诺交期（取自订单）；批次数、已完成批次、完成进度；实际开始日期、预计完成日期（所有批次最新计划结束中最晚的一个）；交付风险；累计延误；红色预警批次。

### 2.5 工艺步骤

- **是什么**：项目的每个步骤一行，提供计件系数、标准周期和排产参数。
- **谁填**：项目组和生产部，排产前填写。
- **要填**：
  - 基本信息：步骤ID（项目号-S步骤号，如 CPo127075-04-S4）、所属项目、步骤号、是否终产品、批次数；
  - 产量与计件：单批投料量、单批产量、预期收率、标准系数（计件用）；
  - 排产参数：标准批次周期（单批天数）、首批计划开始、批次投料间隔、放行等待、上游步骤；
  - 风险信息：敏感化学品、是否三废、主反应釜规格、风险点、规避措施。
- **自动生成**：首批建议结束、末批建议结束、上游首批建议结束、最早可开始、排产检查（首批排得早于上游放行时显示"⚠ 早于上游放行"）。

### 2.6 批次（中枢）

- **是什么**：每个批次一行，是整个系统的中枢。原来的日报、周计划、月计划都从这张表生成。
- **计划员填**（在 ✏️ 排产录入里）：批次ID（项目号-S步骤号-B两位批次号）、所属项目、所属步骤、主车间、批次号、计划版本、V1计划开始/结束、最新计划开始/结束、计划变更原因、拆分说明。
- **车间填**（在 ✏️ 车间更新里）：状态、当前进展、进展说明、实际开始（投料当天）、实际结束（收料当天）、实际产量；月底补三废数量。
- **自动生成**：
  - 排产：建议计划开始/结束、标准批次周期；
  - 延误：开始延误、计划周期、实际周期、周期延误、较V1延误、延误合计、延误次数、未解决延误数；
  - 结果：实际收率、预警等级、预警说明、AI风险提示；
  - 统计标记：本周/下周/本月相关标记、本月计件批次、本月完成计件（这些用于报表筛选和统计，不需要看）。

### 2.7 现场记录

- **是什么**：车间的进展和延误登记，一次一条。合并了原来的进展日志和延误记录。
- **谁填**：车间，在 ✏️ 现场填报表单里填写。
- **要填**：
  - 每条都填：批次、记录类型（进展/延误）、发生时间、当前工序、记录说明；
  - 延误时加填：延误时长(h)、原因分类、负责人、责任人、是否解决（未解决/已解决）、解决措施；
  - 进展记录的"是否解决"选"不适用"。
- **自动生成**：AI建议分类（根据记录说明推荐延误原因，供参考）、大类、项目号、车间、批次状态。

## 三、视图说明

| 视图 | 所在表 | 是什么 | 谁用 |
|---|---|---|---|
| ✏️ 项目登记 | 项目 | 只含项目组要填的字段 | 项目组 |
| ✏️ 步骤登记 | 工艺步骤 | 只含要填的字段，按项目分组；附排产检查结果 | 项目组、生产部 |
| ✏️ 排产录入 | 批次 | 计划员填计划的地方，旁边显示系统建议的计划时间 | 计划员 |
| ✏️ 车间更新 | 批次 | 未完成的批次，按车间分组，车间在这里改状态和实际时间 | 车间 |
| ✏️ 现场填报 | 现场记录 | 表单，登记进展或延误；可以分享链接或放进钉钉工作台 | 车间 |
| 📋 生产日报 | 批次 | 对应原生产日报：在制批次的三套时间、延误天数、进展、收率 | 生产部、项目组 |
| 📋 本周计划 | 批次 | 对应原周计划：计划时间与本周有交集的批次，可导出 Excel | 生产部、厂区 |
| 📋 本周未完成 | 批次 | 对应原"每周未完成批次分析"：本周该投料没投、该结束没结束的批次 | 生产部、管理人员 |
| 📋 下周计划 | 批次 | 下周要做的批次，每周六推送 | 项目组、车间 |
| 📋 本月计划 | 批次 | 对应原月计划上传：本月涉及的批次，含计件和三废 | 生产部 |
| 📋 排产甘特 | 批次 | 按车间分组的甘特图 | 计划员 |
| 📋 预警清单 | 批次 | 红色、黄色预警批次及原因，附 AI 风险提示 | 生产经理、项目主管 |
| 📋 未解决延误 | 现场记录 | 还没解决的延误，按发生时间排序 | 负责人、生产部 |
| 📈 车间统计 | 车间 | 每个车间的在制、预警、本周投入/结束完成率、本月计件完成率、延误 | 生产部、管理人员 |
| 📈 项目统计 | 项目 | 每个项目的完成进度、预计完成、交付风险、累计延误 | 项目主管、管理人员 |

仪表盘有 3 个：**生产总览**（在制、预警、各车间状态、本周投入）、**延误分析**（原因排行、大类占比、车间对比、月度趋势）、**交付**（各项目交付风险）。

## 四、填写规范

### 4.1 编码

| 对象 | 规则 | 示例 |
|---|---|---|
| 项目号 | 类别 + 编号 - 生产次数 | CPo127075-04 |
| 步骤号 | 只写数字；合并步骤用"&" | 4、2&3 |
| 步骤 ID | 项目号-S步骤号 | CPo127075-04-S4 |
| 批次号 | 整数，不写"Batch" | 1、2 |
| 批次 ID | 项目号-S步骤号-B两位批次号 | CPo127075-04-S4-B01 |

### 4.2 三套计划时间

- **V1 计划**：首次审批的计划，审批后不再修改，用来衡量"比原计划晚了多少"（较V1延误）。
- **最新计划**：当前执行的计划。改动时同时更新"计划版本"，并写明"计划变更原因"。
- **实际时间**：车间填写。实际开始填投料当天，实际结束填收料当天。

所有延误、预警和完成率都以**最新计划**为准。

### 4.3 批次状态怎么改

```
未开始 → 备料中 → 进行中 → 已完成
              ↘ 暂停 ↗       （任何阶段都可改为"取消"）
```

- 开始投料时：状态改为"进行中"，并填写实际开始。
- 收料完成时：状态改为"已完成"，并填写实际结束和实际产量。
- 当前进展随工序更新（备料、投料、反应、后处理、离心过滤、干燥、收料、已结束）。

### 4.4 什么时候登记现场记录

- **延误**：只要影响了计划时间就登记，一次延误登记一条，写清楚原因和时长；解决后把"是否解决"改为"已解决"，并填写解决措施。
- **进展**：关键节点（投料、转工序、收料）或有需要留痕的情况时登记一条，不需要每小时都记。

### 4.5 跨车间批次

一个批次按比例在两个车间生产时，"主车间"只选一个，在"拆分说明"里写清比例（如"二车间40%/六车间60%"）。一期的车间统计按主车间计算。

## 五、预警和统计口径

### 5.1 预警等级

| 等级 | 条件 |
|---|---|
| 🔴 红 | 已过最新计划结束日仍未完成；或开始延误 ≥ 2 天；或周期超出 ≥ 2 天 |
| 🟡 黄 | 开始延误 1 天；或周期超出 1 天；或有未解决的延误记录 |
| 🟢 绿 | 其他在计划内的批次 |
| ⚪ 关闭 | 已完成或已取消 |

### 5.2 自动消息

| 时间 / 触发 | 内容 | 接收人 |
|---|---|---|
| 每天 08:30 | 红色、黄色预警批次及原因 | 生产经理、项目主管 |
| 新增延误记录时 | 延误批次、时长、原因、说明 | 负责人、责任人 |
| 每周六 09:00 | 本周未完成批次、下周计划批次 | 项目主管 |

### 5.3 统计口径

- **本周**：周一至周日。**本周计划投入**指最新计划开始在本周的批次，**本周实际投入**指其中已填写实际开始的批次。"结束"同理。
- **本周未完成**：本周该投料的已过计划开始日仍未投料，或本周该结束的已过计划结束日仍未结束。
- **本月计件**：最新计划结束在本月的批次，计件批次数按标准系数计算；本月完成计件指其中在本月实际结束的批次。
- **完成率**对比的是最新计划，不是月初或周初冻结的计划。
- **交付风险**：项目预计完成日（各批次最新计划结束中最晚的一个）对比内部承诺交期。晚于交期显示"🔴 预计超期"，余量不足 7 天显示"🟡"。

## 六、常见问题

| 问题 | 怎么办 |
|---|---|
| 某个批次没出现在"本周计划"里 | 检查最新计划开始和结束是否已填写，以及是否与本周有交集。已经超过计划结束日、还在进行中的批次，在"预警清单"里看 |
| 计划要调整 | 只改"最新计划开始/结束"，同时更新计划版本、写明变更原因；V1 计划不要改 |
| 预警等级、延误天数每天在变 | 正常。这些字段按"今天"自动计算 |
| 想改自动计算的字段 | 改不了，也不需要改。改对应的填写字段（计划时间、实际时间、状态），自动字段会随之更新 |
| 延误原因选不准 | 先参考"AI建议分类"，拿不准就选最接近的一类，并在记录说明里写清楚 |
| 订单交期没显示 | 检查项目的"关联订单"是否已选择，以及订单同步表里是否有这张订单 |
| 原来的 Excel 模板还要不要 | 试点期间并行使用，报表视图可以直接导出 Excel；试点验收后停用 |
