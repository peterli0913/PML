① FDC → 反应/结晶过程的多变量偏差实时监控

优先级 ★★★ 强烈推荐第一个 PoC

在反应过程中实时融合温度、压力、流量、pH、UV、IR 等 20-50 个传感器数据， 用多变量异常检测（PCA / Autoencoder / Hotelling T²）发现"每个参数单看都正常、但组合起来反常"的早期偏差， 并自动分类成已知偏差模式，秒级推送给工艺工程师。

输入
• DCS 实时数据（20-50 tag × 秒级）
• 在线 PAT（IR / 拉曼 / HPLC）
• 历史批次偏差标注库
• 当前批次工艺配方
AI 处理
• 多变量统计模型（PCA / T² / SPE）
• 异常检测（Autoencoder / LSTM）
• 已知偏差分类器（已训练）
• RCA 关联检索
输出
• 异常事件 + 严重等级 + 时间戳
• 自动分类的偏差类型
• 推荐响应动作（推 SCADA + 移动 APP）
• 偏差调查初稿（推 QA Copilot）
解决什么问题
  • 传统 SCADA 单点阈值报警漏报误报多（典型漏报率 30%+）
  • 偏差发现时机晚（人工注意到时往往已不可逆）
  • QA 偏差调查从手工 30-90 天压到草稿 5-15 天
  • 重复偏差自动识别避免漏看
边界 / 凯莱英要做的事
  • 历史偏差标注库（6-12 月由资深 QA 配合做）
  • 反应釜 DCS 数据齐整（缺 tag 要补传感器）
  • 第一阶段定位"决策辅助"，不进 GMP 控制回路
  • 模型对从未见过的"新偏差"召回率有限

② 技术转移 / Golden Path → R&D 到生产的工艺移植加速

优先级 ★★★ CDMO 业务核心

半导体里 WRA + Golden Path 推荐：根据历史成功 wafer 的工艺路径，给新产品推荐最佳生产路径。 CDMO 对应：研发到中试到商业化的工艺包移植 + 设备等效性比对 + 黄金批次推荐。 这一项对 CDMO 业务的杠杆最大 — 缩短 NPI 时间 = 提前确认收入 + 客户复购。

输入
• 研发实验数据（小试/中试）
• 设备能力库（不同反应釜的搅拌/传热）
• 商业化车间设备清单
• 历史相似项目放大数据
AI 处理
• 设备等效性比对（雷诺数、传热系数）
• 历史项目相似度检索
• 工艺参数自动外推
• 放大风险识别
输出
• 商业化车间工艺包草案
• 放大风险清单
• 设备改造建议
• 同类历史项目偏差档案链接
📊 Demo · 设备等效性比对 + Golden Path 推荐　|　 把一个研发项目从 50L 玻璃反应釜（R&D）放大到 5000L 不锈钢反应釜（商业化），AI 自动比对差异 + 推荐参数调整。
工作流程：研发把工艺包提交 → AI 自动比对设备等效性（搅拌 / 传热 / 物料）→ 检索历史相似项目找 Golden Batch → 自动外推参数 + 风险点 → 工程师审核签发商业化工艺包。 典型项目 NPI 时间从 6-9 个月压到 3-4 个月（参考 BMS Devens NPI −42%）。
解决什么
  • NPI 时间长（参考 BMS NPI −42%）
  • 首批成功率低、客户交付延期
  • 工艺包不完整、隐性知识丢失
边界 / 凯莱英要做的事
  • 需要凯莱英历史项目数据沉淀（数百个项目）
  • 设备能力库要标准化（搅拌雷诺数等参数）
  • 需 R&D 部门 + 生产部门 KPI 对齐配合

③ "灵犀" 问答模型 → QA 偏差 Copilot + SOP 助手 + 监管文档生成

监管时间窗已打开

智现未来"灵犀"是半导体专属 LLM。在凯莱英应用为制药专属 LLM — 基于凯莱英历史偏差库 + SOP + MBR + 工艺包向量化， 用 RAG（检索增强生成）给 QA 工程师做偏差调查 / CAPA 拟稿 / 历史相似偏差检索。 AI 不替代签字，但把"找历史、写草稿、填模板"80% 的体力活省下来。

📋 关于"监管时间窗已打开"——什么是 FDA CSA 和 EU Annex 22

过去 GxP（药品 GMP）领域对 AI/ML 应用的合规要求一直模糊，监管不确定性是各家药企不敢落地 AI 的最大顾虑。 2025 年起两份关键文件正式生效，第一次明确告诉行业"AI 在 GxP 用什么条件下合规"——

  • FDA CSA（Computer Software Assurance） — 2025-09 终稿发布 [FDA 官方原文 ↗]
    美国 FDA 关于"计算机化系统验证"的新指南。 把传统 GAMP 5 "证明一切系统都对"的笨重模式，改成"基于风险的、聚焦核心功能"的轻量模式。 明确支持 AI/ML 在 GxP 活动中的使用，鼓励"先用、迭代、有审计追踪即可"。
  • EU GMP Annex 22 — 2025 起施行 [EU EudraLex Volume 4 ↗]
    欧盟 GMP 指南第一次正式承认 AI 系统可作为药品放行决策的辅助工具。 要求"风险分级 + 透明可解释 + 人工最终签字 + 持续监控漂移"四个原则。

对凯莱英的意义：现在做 AI QA Copilot 有了明确合规路径—— 早做的人吃到"合规先发优势"红利，晚做要在监管检查时面对越来越严的"为什么你们没做"的反向问询。

输入
• 当前偏差描述
• 该批次 DCS 实时数据
• 历史偏差库（向量化）
• SOP / MBR / 工艺包知识库
AI 处理
• RAG 检索 Top-K 相似偏差
• LLM 综合生成根因建议
• 根据 SOP / CAPA 模板拟稿
• 标出所有引用源
输出
• 偏差调查初稿
• CAPA 模板（已填关键字段）
• 同类历史偏差关联链接
• 引用源文档 + 条款

④ 预测性维护 (PdM) → 关键设备健康监测 + 剩余寿命预测

智现未来核心算法 — 可移植性强

智现未来在半导体里给光刻机、刻蚀机、真空泵、CMP 等高价设备做 PdM—— 数千个 tag × 多变量 + 时序模型预测剩余寿命 (RUL, Remaining Useful Life)。 用的算法（LSTM 时序模型 + 多变量异常检测 + 故障模式分类器）与 CDMO 关键设备完全通用。

智现未来已有算法的核心优势
  • 12 吋晶圆厂关键设备 PdM 经验积累 20+ 年（含 BISTel 时期）
  • 多变量时序模型（LSTM / TCN）+ 故障模式聚类
  • 剩余寿命 RUL 预测带不确定性置信区间（不是单点预测）
  • 设备健康得分（0-100）与运维工单系统联动
  • 跨设备类型的迁移学习能力（光刻机 → 刻蚀机）
CDMO 上对应的高价值设备
  • 反应釜搅拌器（机械密封 / 减速机 / 电机）— 单次失效 = 整批料报废
  • 离心机（高速旋转部件 / 振动）— 故障可能引发安全事故
  • 冰机 / 螺杆压缩机— 公辅核心，失效 = 全厂停产
  • 真空泵— 多用途，故障导致工艺中断
  • 纯水系统泵 / 膜组件— 微生物风险高
可移植性论证： 半导体光刻机 → CDMO 反应釜的迁移在算法层是零成本，只需要把振动 / 温度 / 电流 / 声纹等传感器数据接入， 模型参数会自动重训。智现未来的"跨设备类型迁移学习"框架可以复用—— 这是他们的成熟算法资产，相对其他通用 PdM 供应商有明显的方法论优势。

PART 06 · 数据安全 & 客户版权隔离

CDMO 业务命脉 — 不同客户的经验不能互通，AI 也不能

凯莱英给客户 A 做了一个反应工艺，从中积累了"催化剂 X 在 80℃ 这种条件下副产物 Y 高"的经验。 这条经验能不能用在客户 B 的项目上？— 法律和商业道德都不允许直接用。 但 AI 模型天然喜欢"跨客户学经验"，这是 CDMO 用 AI 最大的伦理 + 法律风险。本部分给出三层隔离方案。

三层隔离的具体实现

隔离层 实现方式 解决的风险 合同 / 流程支持
L1 · 物理 / 逻辑数据隔离 • 每个客户独立数据库 schema 或独立集群
• 客户访问严格按"项目权限"过滤
• 审计日志追到"用户 × 客户 × 操作" 		"原始数据不出客户域" 客户合同明确数据归属；ISO 27001 + Part 11 审计
L2 · 模型 / 参数隔离 • 客户专属微调模型不混用
• 联邦学习 / 差分隐私训练
• 共享层仅是通用底层算法（如 PCA / Transformer 架构本身） 		"模型参数不暴露客户数据细节" 合同写入"AI 模型训练许可" + "不得对外提供训练后模型"
L3 · 经验 / 知识沉淀脱敏 • 设"知识沉淀脱敏委员会"评议每条经验是否可外传
• 可跨客户共享：方法论 / SOP 模板 / 设备参数库（不含工艺细节）
• 不能共享：CPP 数值 / 杂质谱 / 催化剂体系 / 产物结构 		"经验抽象可共享、具体细节不可" 客户合同"脱敏经验沉淀许可"；IP 影响评估流程
关键风险 1 · 联邦学习不是万能

联邦学习理论可让"数据不出客户域、模型参数互通"。但模型参数本身可能反推出训练数据特征（model inversion attack）。 必须叠加差分隐私 + 严格审计。

关键风险 2 · 智现未来现场没回答这个

现场我们提出客户数据隔离问题，对方未给出明确方案。 这是 PoC 启动前必须落实的硬指标，应作为合同附件。

关键参考 · 半导体 Foundry 已有成熟方案

台积电 / 三星给数百家 IC 设计公司代工，半导体 Foundry 客户数据隔离方案是行业最严的之一。 智现未来在这一块的经验可以直接迁移 — 但需要他们主动给方案。

附录 · 半导体 ↔ CDMO 制药 术语对照

智现未来"行话" → 凯莱英能听懂的话 — 平移可行性的基础

业界很少有人把这两个行业放在一起讲，但"软"的逻辑层（数据建模、批次追溯、根因分析、AI 算法）出奇地相似， "硬"的物理层（设备、工艺、合规）完全不同。读懂这张表是理解前面所有方案的前提。

概念域 半导体（智现未来主场） CDMO 制药（凯莱英） 相似度 / 差异说明
生产单元 Wafer / Lot（晶圆 / 批次，每片或每盒 25 片） Batch / Lot（批次，每批数百公斤到吨级） ★★★ 高度同构
都是"独立可追溯的最小生产单元"，都有 ID、家谱、产出物属性
生产履历 Lot Genealogy + WRA（Wafer Run-time Analysis） Batch Record (MBR/EBR) + 物料谱系 ★★★
都是"完整记录每一步操作 + 参数 + 设备"
最优生产路径 Golden Path（黄金路径，最佳工艺组合） Golden Batch（黄金批次 / Optimal Run） ★★★
逻辑完全一致，都是"找出历史最好批次的工艺参数轨迹作为新批次模板"
实时多参数监控 FDC（Fault Detection & Classification） 过程偏差实时监控（业界还在初级阶段，多数厂仍是单点阈值） ★★★
CDMO 比半导体落后 5-10 年，引入后效益巨大
工艺配方 Recipe（每步几十个参数） MBR + SOP + CPP/CQA ★★ 概念同构、形式不同
CDMO 配方有 GMP 监管要求，每个变更都要 Change Control
批间反馈优化 R2R（Run-to-Run Control） DoE 自动化 / 贝叶斯优化 / 黄金批次反馈 ★★★
凯莱英连续流是天然的 R2R 平台
异常 / 超规 OOS / Excursion（Out-Of-Spec） Deviation / OOS ★★★
流程相似（发现 → 调查 → CAPA），CDMO 多了 GMP 文档体系
根因分析 RCA Auto-Trace（YES 自动溯因） CAPA Root Cause ★★★
智现未来 YES 自动溯因可直接迁移为 CAPA Copilot
业务模型 Foundry（代工模式，同产线为多个 IC 设计公司代工） CDMO（代工模式，同产线为多个药企代工） ★★★ 高度同构
"产线复用 + 客户隔离"的核心管理逻辑相同
客户数据 Customer Wafer Design（客户产品设计绝密） 客户 API / 工艺包（客户产品工艺绝密） ★★★ 同构
客户隔离要求严苛程度相同；解决方案可借鉴
设备类型 光刻机 / 刻蚀机 / CVD / CMP 反应釜 / 结晶器 / 干燥机 / 离心机 ★ 完全不同
物理层、传感器、控制系统差异巨大，要重做
合规体系 IATF / ISO 9001 / 客户审计 21 CFR Part 11 + GAMP 5 + GMP + NMPA ★ 完全不同
CDMO 合规要求严得多；智现未来需补 GAMP 5 类别 4 验证
DCS / OT 协议 SEMI E10/E30/E40/E87（半导体专属） OPC UA + Modbus + DCS 厂商专属（Honeywell / 横河 / Emerson / 西门子） ★ 完全不同
智现未来产品需做制药 DCS 接口适配
AI 算法适用性 PCA / Autoencoder / LSTM / RL / MPC / 大模型 + RAG 同类算法直接适用 ★★★ 完全相同
数学模型层无任何差异
一句话总结：业务逻辑层和算法层 可平移；物理设备层、合规层、协议层 需重做。 平移工作的 70% 难度在"重做"那 3 层。
