# MOR 生成工具 v0.1 的输出样例

这些是用 `qwen-skills/mor-generator` 生成的初稿，用来和本目录上一级里的专家定稿对比。使用方法见 `qwen-skills/mor-generator/SKILL.md`。

## v3_留出测试

工具只学了 v.2 这一对（Tech-DH313839301_v.2 + MOR-DH313839301.02），再用它生成 v.3。v.3 的专家定稿没有参与学习，专门用来测试效果。

| 文件 | 内容 |
|---|---|
| `MOR-DH313839301.03_草稿.docx` | 生成的初稿：黄色高亮是待人工填写的内容 |
| `MOR-DH313839301.03_草稿.生成报告.md` | 每个 Ins 的来源（复用了哪个例子或操作库模块）、需要填写和建议核对的项 |
| `MOR-DH313839301.03_草稿.复核报告.md` | 复核结果：错误、提示、自动修正、高亮清单 |
| `对比报告.md` | 初稿与专家定稿 MOR-DH313839301.03 的逐项对比 |
| `mor_plan.json` | 中间计划（AI 补写后的版本） |
| `ai_fills.json` | AI 补写的 5 处内容 |

结果：Ins 标题 22/22 一致，文字相似度 0.84，原料行 12/12，内部控制号 5/5，复核错误 0。
