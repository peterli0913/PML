# 一页式纪要模板

## 模板

```markdown
# 【纪要】{会议主题}

{日期 时间段} ｜ 主持：{姓名} ｜ 参会：{姓名、姓名…} ｜ 关联项目：{项目A、项目B}

## 一、会议结论
1. 【{项目}】{结论，一句话，含关键数字/条件}
2. ……
（只写"已决"事项，3–5 条；没有已决事项时写"本次无最终决议"，并说明卡在哪里）

## 二、行动项
| # | 事项 | 负责人 | 截止 | 交付物/完成标准 |
|---|---|---|---|---|
| 1 | {动词开头} | {姓名} | {MM-DD 或 未明确} | {可验收的产出} |

## 三、议题要点
### 议题1 【{项目}】{要解决的问题}
- 背景：{一句话，可选}
- {姓名}：{主张}，因为{依据/数据/风险}
- {姓名}：{不同意见或补充}
- → 结论：{已决内容 / 待决：需{谁}于{何时}拍板}

### 议题2 ……

## 四、待决与待确认
- 待决：{事项} — 需{谁}拍板，建议{时间}前
- 待确认：{疑似误识别的术语/说话人/数字}
```

## 写作规范

| 规范 | 正确示例 | 错误示例 |
|---|---|---|
| 主语明确 | 王五牵头梳理放行风险清单 | 需要梳理一下风险 |
| 书面化 | 建议以标准谱图比对替代逐项目专属检测 | 我觉得那个就是说能不能谱图叠加一下 |
| 结论写结果，不写过程 | 同意先做 A 模块，B 优化后置 | 大家讨论了 A 和 B 的先后顺序 |
| 数字保留 | 甲醛限度达 ppb 级，现有方法难以检出 | 甲醛限度很低 |
| 不引用原文 | （概括后的书面句） | "他说：'这个肯定得让陈总拍板'" |
| 一句话一件事 | 拆成两条 | 一条里塞三个动作 |

## 篇幅控制

- 正文目标为 600–1000 字，超出时按以下优先级删减：
  1. 删 C 级观点中重复支持同一结论的条目；
  2. 删"背景"行；
  3. 合并同项目议题。
- 绝不删除：结论、行动项、待决事项。
- 议题要点每个议题不超过 4 行。

## 禁止出现

- "会议气氛热烈""大家积极讨论"之类的空话
- 逐字稿原句、时间戳、"说话人1"（除非身份未确认，且已放入待确认）
- 听记自带的"关键词""思维导图""发言占比"等区块
- 会上没有讲到的上下文信息
