# 重点与噪音判定标准

会议以实务、决策和执行为主。判定的核心问题只有一个：**这句话会不会改变后续由谁、做什么、怎么做？** 会改变就保留，不会就删。

## A 决议信号

- 拍板类表达："就这么定""先按 X 做""同意""不做了""放到后面""以 X 为准"
- 由有决策权的人（见人员表的"决策权限"）表达的明确选择
- 对之前决议的推翻或修改：必须写明"变更：原 X → 现 Y"，并在记忆更新块中把旧决议标记为"被替代"

注意："我觉得可以""应该没问题"不算决议。只有在没有人反对、并且随后有人据此分工时，才算已决；否则记为待决。

## B 行动信号

- 承诺："我来""我这两天跟 X 碰一下""我回去查一下"
- 指派："你牵头""你跟 X 沟通""下周给我"
- 会后才能完成的检查和确认（例如"回去查 SOP 里的要求"），这类常被漏掉，**必须抓**

## C 建设性观点（每个议题最多保留 3 条）

保留以下几类：
- **方案或替代思路**：例如"用通用方法 + 标准谱图库，替代逐项目专属检测"
- **依据或数据**：数字、限度、频次、成本、时长、对比结果
- **风险或约束**：合规（QA/QC/注册）、安全、产能、客户要求、成本
- **范围或优先级判断**：先做什么、后做什么、不做什么
- **跨部门依赖**：需要 QA、QC、仓库、EHS 或客户配合的事项

## D 背景

现状描述和历史回顾。只在不写就看不懂议题时保留一句。

## X 噪音（删除）

- 寒暄、开场、等人、设备调试
- 口头禅和重复确认（"对吧""对对对""是吧"）
- 同一观点的反复表述（只保留表述最清楚的一次）
- 没有依据的抱怨、情绪表达
- 与本会主题无关的插话或跑题
- 发散讨论中最终被放弃、而且放弃本身也不重要的分支

## 制药/CDMO 场景的重点信号（命中即提高保留优先级）

- 合规与质量：QA、QC、放行、偏差、变更控制、CAPA、SOP、验证、审计、注册申报
- 物料与检测：规格、专属方法、通用方法、取样、检测项、限度（ppm/ppb）、标准谱图、方法编号（如 AM-xxx）
- 生产与设备：批次、产能、罐区、打料、清洁、设备故障、停机
- 客户与项目：战略客户、项目专属要求、交付节点
- 决策层：需要某位领导或负责人拍板的事项，一律进"待决"

## 常见漏抓点（自检时重点看）

1. 会议后半段的分工往往说得很快、很口语化，最容易漏掉。
2. "这个要让 X 拍板"是待决事项，不是闲聊。
3. 同一物料或方法牵涉多个项目时，要写明涉及哪些项目或基地。
4. 一个人连续长段发言里，常常夹着一个关键数字或约束。
