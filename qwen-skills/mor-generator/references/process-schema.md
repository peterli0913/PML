# 结构化工艺步骤表

每个工艺步骤是一行。一个工艺段落包含多个动作时（例如"加入 X，升温至 60 ℃，保温 2 h"），拆成多行，每行只有一个单元操作。

## 字段

| 字段 | 说明 | 示例 |
|---|---|---|
| 步骤号 | S1、S2…；子步骤写 S3.1 | S3.1 |
| 工序 | 所属工序或阶段 | 第 2 步 缩合反应 |
| 单元操作 | 取自单元操作库的类型名 | 升温 |
| 设备 | 工艺写了就填；没写就写 `【待补】`，或填设备库中按车间匹配的建议值（标"建议"） | R-201（建议） |
| 物料 | 名称、用量、单位、当量/倍量，可多个 | 乙腈 50.0 L（10 V） |
| 参数 | 参数名、目标值、范围、单位，可多个 | 内温 60 ℃（55–65 ℃） |
| 时间/速率 | 时长、滴加速率、升降温速率 | ≥ 2 h；≤ 20 ℃/h |
| 终点/判据 | 什么条件下进入下一步 | IPC：SM ≤ 1.0% |
| IPC | 取样点、检测项、方法、标准 | HPLC，SM ≤ 1.0% |
| 安全/EHS 要求 | 工艺中写明的要求 | 氮气保护 |
| 关键标识 | CPP / 关键步骤 / 暂停点，按工艺标注 | CPP |
| 出处 | 文件、页码、段落 | 工艺 P5 第 2 段 |
| 置信度 | 高 / ⚠ 待确认（附原因） | ⚠ 原文为"约 60 度" |

## 抽取规则

- **数值照抄原文**，不做单位换算，不做四舍五入。需要换算的（例如 V → L），在 MOR 组装时计算，并保留算式供核对。
- 原文是模糊表达（"约""适量""数小时"）时，原样保留，并标 ⚠。
- 原文的范围和目标值都要抽取；只有一个值时，不要自己编范围。
- 工艺中引用其他文件的（例如"按 SOP-xxx 操作"），把引用保留在"安全/EHS 要求"或备注里。
