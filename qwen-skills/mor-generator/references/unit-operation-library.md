# 单元操作库与 MOR 知识底座

所有表都建在"企业上下文库"Base 中。

## 表结构

### 单元操作库
| 字段 | 说明 |
|---|---|
| 操作类型 | 例如：投料、升温、保温反应、滴加、IPC 取样 |
| 触发词 | 工艺中常见的表达，用 `;` 分隔，例如"加入;投入;charge" |
| 标准段落模板 | 带 `{槽位}` 的 MOR 标准写法 |
| 必填记录项 | MOR 中需要操作人填写的项目，例如：实际温度、起止时间 |
| 签字点 | 操作人 / 复核人 / QA |
| 注意事项 | 本操作的通用安全或质量提示，**须来自公司规范** |
| 历史实例 | 2 个真实 MOR 片段（对应的出处） |
| 版本 / 状态 | v1.2 / 生效 |

### MOR 编写规则
规则 / 类别（数值、范围、单位、术语、编号、格式、签字）/ 示例 / 来源（SOP 或专家批注）/ 状态 / 版本。

### 设备库
设备编号 / 设备类型 / 容积或规格 / 车间 / 材质 / 备注。

### 物料库
物料名称 / 物料编码 / 别名 / 类别 / 备注。

关联字段（`bidirectionalLink`）：单元操作库.适用设备类型 → 设备库（可选）。

建表命令与会议纪要 skill 相同：先用 `+table-bootstrap` 建 text 字段，再补关联字段。

## 示例模板

以下为**通用写法示例**，正式内容以公司 MOR 规范和专家审核为准，阶段 2 会被替换。

| 操作类型 | 标准段落模板（示例） | 必填记录项 |
|---|---|---|
| 投料 | 核对{物料名称}的物料编码、批号及状态标识无误后，称取{物料名称}{用量}{单位}，经{加料方式}加入{设备}。 | 物料批号、称量值、称量人、复核人 |
| 溶剂加入 | 向{设备}中加入{溶剂名称}{体积}{单位}（{倍量}）。 | 实际加入量、起止时间 |
| 升温/降温 | 开启搅拌，将{设备}内温调至{目标温度}（{温度范围}），控制速率{速率}。 | 起始温度、到温时间、实际温度 |
| 保温反应 | 于{温度范围}保温反应{时长}。 | 保温开始/结束时间、每{间隔}记录一次温度 |
| 滴加 | 控制内温{温度范围}，滴加{物料}，滴加时间{时长}。 | 滴加起止时间、过程最高温度 |
| IPC 取样 | 取样检测{检测项}（{方法}），标准：{标准}。符合标准后进入下一步；不符合时按{处理方式}处理。 | 取样时间、取样人、检测结果、判定 |
| 过滤/离心 | 将物料经{设备}过滤，用{淋洗液}{用量}淋洗滤饼。 | 起止时间、滤液状态 |
| 干燥 | 于{温度范围}、{真空度}下干燥至{终点判据}。 | 干燥起止时间、温度/真空记录、终点检测结果 |

单元操作库在阶段 1 聚类完成后补全，预计 15–25 类：还有淬灭、萃取分液、洗涤、浓缩/蒸馏、结晶/析晶、打浆、转料、氮气置换、包装、清场等。
