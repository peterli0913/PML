# 自动核对清单

核对对象：MOR 草稿（或专家修改后的版本）与结构化工艺步骤表。能用代码比对的一律用代码，不靠模型"看一遍"。

## 错误（必须修改）

| # | 核对项 | 方法 |
|---|---|---|
| E1 | 数值一致 | 抽取 MOR 中的全部数值和单位，逐一匹配步骤表；不匹配，或在步骤表中找不到出处的，算错误 |
| E2 | 步骤完整 | 步骤表中的每一步，在 MOR 中都有对应段落（按出处标记匹配） |
| E3 | 步骤顺序 | MOR 中的步骤顺序与工艺一致 |
| E4 | IPC 完整 | 工艺中的每个 IPC 在 MOR 中都有取样、标准、判定和不合格处理 |
| E5 | 物料完整 | 工艺中的所有物料都在 MOR 中出现，名称与物料库一致 |
| E6 | 换算正确 | V→L、当量→质量等换算，重算后结果一致 |
| E7 | 无编造内容 | MOR 中没有工艺和规则库都找不到出处的参数或要求 |

## 提示（建议人工确认）

| # | 核对项 |
|---|---|
| W1 | 签字点符合规则库要求（关键步骤需复核人签字等） |
| W2 | 必填记录项齐全（按单元操作库） |
| W3 | 单位、范围写法符合编写规则 |
| W4 | 标 `[AI]` 的段落 |
| W5 | 工艺中标 ⚠ 的模糊表达是如何处理的 |
| W6 | `【待补】`项清单 |
| W7 | 设备容积与物料体积匹配（体积 ≤ 设备有效容积，需设备库支持） |

## 报告格式

```markdown
## MOR 核对报告：{产品}/{工序}  {日期}
结果：错误 {n} ｜ 提示 {n} ｜ 待补 {n}
### 错误
| # | 位置 | 问题 | 工艺出处 | 建议 |
### 提示
### 待补清单
```
