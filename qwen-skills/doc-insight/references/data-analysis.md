# 数据分析

## 步骤

1. **明确问题和口径**：用户要回答什么问题？统计周期、单位、去重规则、"异常"怎么定义？不清楚时先给出一个默认口径，请用户确认后再算。
2. **检查数据质量**：行数、缺失率、重复行、异常值（例如负数、超出物理范围的值）、单位混用、合并单元格、多级表头。有问题先报告，再说明处理方式。
3. **用代码计算**：使用 pandas，保留计算过程；结果数字直接取自代码输出。
4. **出图（需要时）**：每张图只说明一件事，标题直接写结论（例如"Q3 偏差数同比增加 40%"），而不是"偏差数趋势图"。
5. **写结论**：按下面的输出格式。

## 输出格式

```markdown
## 结论（≤3 条，每条带数字）
## 关键发现
| 发现 | 数据 | 说明 |
## 数据质量与局限
- 口径：……
- 已处理：删除重复 N 行，……
- 局限：样本量小 / 缺少 X 字段 / 不能推断因果
## 建议的下一步
```

## 常用分析清单（按场景选用）

| 场景 | 分析 |
|---|---|
| 趋势 | 按月/周汇总，环比/同比，移动平均 |
| 构成 | 占比、帕累托（找出贡献 80% 的少数项） |
| 对比 | 分组对比（基地、产线、项目、供应商），差异是否显著 |
| 异常 | 控制限（均值 ± 3σ）、离群点、突变点 |
| 质量/生产 | 偏差按类型和根因分布，CAPA 关闭及时率，批次收率分布，设备停机 Top N |
| 进度 | 计划与实际对比，延期项按负责人和原因分布 |

## 知识库附加表（与企业上下文库同一个 Base）

```bash
dws aitable +table-bootstrap --base-id <BASE_ID> --name "文档索引" --fields '[
 {"fieldName":"文件名","type":"text"},{"fieldName":"类型","type":"text"},{"fieldName":"日期","type":"text"},
 {"fieldName":"一句话结论","type":"text"},{"fieldName":"关键数字","type":"text"},{"fieldName":"链接","type":"text"}]'

dws aitable +table-bootstrap --base-id <BASE_ID> --name "实体" --fields '[
 {"fieldName":"名称","type":"text"},{"fieldName":"类型","type":"text"},{"fieldName":"别名","type":"text"},
 {"fieldName":"释义","type":"text"},{"fieldName":"关系","type":"text"},{"fieldName":"来源","type":"text"},{"fieldName":"状态","type":"text"}]'
```

建表后补关联字段（`bidirectionalLink`）：
- 文档索引.关联项目 → 项目卡片
- 实体.关联项目 → 项目卡片
- 实体.负责人 → 人员

"实体"表存放设备、供应商、物料、系统等暂时没有专表的对象。同一类实体超过 50 条时，再单独拆成专表（例如"设备"表），供 MOR 工具复用。
