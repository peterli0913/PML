# 速读模板

所有模板的开头都相同：

```markdown
# 【速读】{文件名}
{类型} ｜ {作者/来源} ｜ {日期} ｜ 关联：{项目}
**一句话结论**：……
```

## 方案 / 报告
```markdown
## 关键数字
| 指标 | 数值 | 出处 |
## 核心内容（≤5 条）
## 风险与疑点
- 与{历史决议/其他文件}不一致：……
- 缺失：……（例如没有成本、没有时间表、没有验收标准）
## 需要你决策/跟进
1. {动词开头} — 建议{谁}跟进
```

## 供应商方案 / 报价
重点关注：范围边界（包含什么、不包含什么）、价格构成、交付周期、我方需要投入的人和数据、知识产权和数据归属、验收与付款节点、同类案例是否可信（是否需核实）。

额外输出一节 **"建议追问供应商的问题（≤5 条）"**。

## 合同 / 协议
重点关注：金额与付款、交付和验收、违约责任、保密与数据、知识产权、终止条款、对我方不利或不对等的条款。

额外输出一节 **"需法务确认的条款"**。

## 会议材料 / 汇报 PPT
重点关注：汇报人要我做什么决定、请求了哪些资源、数字是否前后一致、与上次汇报相比有什么变化（对照项目卡片的最近进展）。

## 数据表
用 `data-analysis.md` 的输出格式。

## 法规 / 指南
重点关注：适用范围、与现状相比的新增或变化要求、生效时间、对哪些部门或流程有影响。

额外输出一节 **"差距自查清单"**。条款原文以官方文本为准，标"需核实"。
