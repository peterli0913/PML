# 消息模板

语气：简洁、礼貌，像本人在发消息。不写"我是 AI 助手"。如果用户希望注明代发，可在末尾加"（由{用户}的办公助手代发）"。

## 1. 时间确认（每人一条）

```
{称呼}好，{用户姓名}想约一个会：{会议主题}（约{时长}分钟，{线上/线下}）。
以下时段您哪些方便？
1. {11-12 周三 14:00-15:00}
2. {11-13 周四 10:00-11:00}{；日历显示您此时段有安排，如可调整仍可选择}
3. {11-13 周四 15:30-16:30}
请直接回复编号，可多选（如"1、3"）；都不方便请回复"都不行"，并告诉我您方便的时间。
麻烦在{截止时间}前回复，谢谢！
```

规则：
- 日历显示忙的时段，要附上分号后那句提示，不要直接把这个时段删掉。
- 称呼优先用人员表中的称呼（陈总、于博士），没有就用"姓名 + 老师"。

## 2. 截止前提醒（只发一次）

```
{称呼}好，提醒一下{会议主题}的时间确认，{截止时间}前回复编号即可：1. {…} 2. {…} 3. {…}
```

## 3. 追问（只在回复含义不清时发，最多一次）

```
收到，想确认一下：您是指{解读}吗？
```

## 4. 结果通知：不能参加者

```
{称呼}好，{会议主题}定在{时间}，这次和您的时间没能对上，会后会同步纪要。如需参与讨论的内容，可以先发给{用户姓名}。
```
